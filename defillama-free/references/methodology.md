# 数据解释和计算约束

DefiLlama 通过公开适配器收集链上合约、事件、索引服务及项目接口等数据，来源因项目和指标而异。可检查 [TVL 适配器](https://github.com/DefiLlama/DefiLlama-Adapters)、[维度适配器](https://github.com/DefiLlama/dimension-adapters) 及返回的 methodology。不是所有指标都直接读取链上，也不是审计后的公司财务报表。

## 时间与缺失

所有窗口按 UTC 处理，用户起止日期包含两端，输出区间为开始午夜至结束日次日午夜的半开区间。默认取参与比较且有资格的序列中最晚完整日的共同交集终点，披露较新的舍弃日期。指定日期不能偷偷平移。前期窗口等长且紧邻本期。

流量必须先有可核查的自然日区间证据，再检查每日有限数值是否齐全；缺日或 null 时比较值为空，已观测部分可单列 partial_sum。不补零、不前向填充；滚动或未知区间即使日期齐全也不具有资格。上游 total24h/7d/30d 保持来源报告值，不能冒充重建的日历窗口。当前已验证范围见 [时间映射](time-semantics.md)。

存量取指定结束日内最后一条真实快照，与 N 天前结束日快照比较；最新快照为 null 时不回退，不使用邻近日期补齐，不累加存量。观察时间未知时保留未知，抓取时间和 HTTP Date 不替代观察时间。

变化率仅在前值为正时计算；零或负基准给出原因。负收入保留，不按缺失处理。返回点齐全与上游统计完整性是不同概念：保留采集健康标记，不能从 HTTP 200 推断完整；有效的旧历史也不因最新抓取失败一概作废。

## 实体、范围和派生指标

协议 ID、父子关系、版本和已知链覆盖均参与校验。名称相似不足以确认身份，同父级不代表同统计范围。只有同实体、同范围、同窗口、同单位的完整数据才计算费用／成交量和收入／费用；跨协议比较注明类别和范围差异。

手续费留存率不是净利率。费用减收入减 supply-side 的残差按每日报告，容差取每日日数对应的 1 美元或费用规模的百万分之一较大者；不能用残差发明工资、税费或营销开支。收入变化拆解仅表示算术关系，不证明原因。

稳定币非美元锚定资产不能按原币供应量以 1:1 美元相加。历史估值使用上游 totalCirculatingUSD；供应量与价格分别保留。池收益的基础、奖励、总 APY 分开，缺失不是 0。期权 premium 和 notional 不互换，OI 是观察时刻存量。

## 输出与复现

JSON 包括 schema_version、生成时间、请求／实际范围、sources、results、warnings 和总体状态。结果逐项保留来源 ID、口径、窗口、缺失原因与覆盖情况。`--raw` 才额外附带原始响应。CSV 每个标量字段一行，保留结果编号、实体、指标、窗口和来源，避免将嵌套对象藏在单元格中；文本公式前缀会转义。

API 会修订历史数据；复现时记录抓取时间、完整 URL、请求窗口与代码版本。不要将实时观察值或网络失败写成长期保证。
