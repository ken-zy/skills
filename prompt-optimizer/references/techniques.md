# 可选提示词技法

模板按任务改写，不强制角色、固定问题数或分阶段暂停；假设复盘须标为假设，不编造真实案例。

## Eight Techniques

### T1: Role Selection (角色选定)

**When:** 需要专业领域建议，但不确定该找什么角色。

**Template:**
```
我想咨询关于 [领域/问题] 的建议。

请你先从该领域选择一位最适合回答这个问题的真实顶尖专家（历史或当代均可），说明你选择这个人的理由。

在开始前，你可以先问我 2 个定位问题，帮助你更准确地选择专家角色。

选定角色后，请以该专家的视角、思维方式和专业深度来回答我的问题。

我的问题是：[具体问题]
```

**Key:** 真实人物适合思维方式独特且广为人知的场景（"乔布斯谈产品"）；泛化角色适合需要特定技能组合的场景（"有10年经验的 SRE"）。优先选择你能说清"这个人会怎么想"的角色。

---

### T2: Socratic Questioning (苏格拉底追问)

**When:** 问题复杂、信息量大，直接问容易得到泛泛回答。日常使用频率最高。

**Template:**
```
我想请你帮我 [目标描述]。

但在给出方案之前，请你先通过追问来充分了解我的情况。规则如下：
- 先判断哪些缺失信息会实质改变方案，并按影响大小排序
- 每次只问我一个信息增益最高的问题
- 根据我的回答继续追问
- 当你收集到以下信息后，给出完整方案：
  1) 我的具体场景和背景
  2) 我已尝试过的方法（如有）
  3) 成功的定义标准
  4) 主要约束条件（时间、资源、技术栈等）
- 如果某项信息对方案质量影响不大，可以跳过
- 一旦现有信息足以做出可靠判断，就停止追问；不要为了完成清单而提问
- 给出方案时，说明你基于哪些关键信息做出的判断

我的初始背景：[简要背景]
```

**Key:** 用“是否会改变方案”给问题排序，并用具体信息清单作为停止条件。比固定追问轮数或置信百分比更可靠、更可控。

---

### T3: Critical Examination (批判性检验)

根据任务目标选择一种模式：

- **T3-A 对抗式压力测试**：用户已有明确观点，想找漏洞、准备答辩或做红队检验
- **T3-B 双向钢人决策**：用户需要比较选项、形成判断，或担心 AI 只会顺着自己说

不要混用两种目标。T3-A 追求发现最强反例；T3-B 追求在同一标准下比较各方并形成取舍。

#### T3-A: Adversarial Stress Test (对抗式压力测试)

**Template:**
```
我有一个观点/方案，请你扮演一个强硬的反对者来与我辩论。

规则：
- 你的目标是找出我观点中的所有弱点
- 优先攻击最关键的假设，而非边缘细节
- 如果某个论点确实很强，承认它很强，然后去找下一个弱点
- 不要迎合我，也不要为了反对而反对
- 如果我反驳了你的某个论点，立即换一个更强的角度继续挑战
- 直到你真的找不到可以反驳的角度，再告诉我哪些部分经受住了考验、哪些仍有隐患
- 明确区分事实、推断和假设；不要编造数据、案例或来源

我的观点是：[你的观点/方案]
```

**Key:** 适合演讲、分享、评审或答辩前检验观点完善度，不适合需要中立比较多个方案的决策。

#### T3-B: Bidirectional Steelman (双向钢人决策)

**Template:**
```
我正在考虑这个问题、观点或方案：

[填写内容]

先不要直接给出结论，也不要默认我已经正确描述了问题。请分两个阶段处理。

第一阶段：问题澄清与双向钢人

1. 重述我真正需要解决的问题，区分：
   - 表面问题
   - 真实目标
   - 成功标准
   - 主要约束
   - 隐含假设

2. 将我当前倾向的观点强化成最合理、最难反驳的版本：
   - 最强理由
   - 最有力证据
   - 成立条件
   - 能解释哪些事实

3. 将最强的反对观点或替代方案做同等程度的强化：
   - 最强理由
   - 最有力证据
   - 成立条件
   - 对当前观点最难回答的质疑

4. 使用相同标准比较双方，并明确区分：
   - 已知事实
   - 基于事实的推断
   - 尚未验证的假设

   不得为了强化论证而编造事实、数据、案例或来源。

5. 找出最可能改变结论的 1-3 个关键变量，并说明：
   - 变量处于什么条件时更支持当前观点
   - 变量处于什么条件时更支持反对观点
   - 是否存在明确的判断阈值

6. 只向我提出一个信息增益最高的问题，然后停止。这个问题必须能够实质改变最终判断；不要询问仅用于补充背景、但不会改变结论的信息。

第二阶段：在我回答后

给出：
1. 明确判断
2. 三条核心理由
3. 判断成立的条件
4. 最强反方意见，以及为什么它仍未改变结论
5. 最大不确定性
6. 下一步最小可执行行动

不要为了显得中立而机械地各打五十大板。如果现有证据明显偏向一方，直接说明。不要输出谁都能套用的通用建议。
```

**Key:** 双向钢人强化的是论证质量，不是真实性。必须使用同一标准比较双方，并防止虚假平衡和未经核验的“强证据”。

### T4: Pre-mortem (预演失败)

**When:** 有具体计划/方案，需要提前发现风险和盲区。

**Template:**
```
以下是我的 [项目/计划/方案]：

[方案内容]

现在请你假设这个项目已经在 6 个月后彻底失败了。请以事后复盘的视角回答：

1. 最早出现的衰退信号是什么？出现在什么时间点？
2. 哪个决策是致命错误？当时为什么看起来是对的？
3. 有哪些被忽视的核心风险？
4. 如果重来，第一个要改的事情是什么？
5. 请基于真实的类似案例，写一篇简短的"失败复盘文章"

请尽可能具体，不要泛泛而谈。
```

**Key:** 人和 AI 都倾向乐观，这个心法强制切换到悲观视角。

---

### T5: Reverse Prompting (反向提示)

**When:** 有想要的成品范例，但不知道怎么描述需求。

**Template:**
```
这是我想要的成品范例：

[粘贴成品内容/上传图片]

请你：
1. 分析这个成品的结构、风格、节奏和关键特征
2. 倒推一个提示词，让我用它能稳定生成同风格同质量的内容
3. 逐句说明提示词中每一部分的作用
4. 指出哪些元素是风格核心（必须保留），哪些是可替换的变量
```

**Key:** 目的是学习结构和节奏规律，不是机械复制。支持文字和图片。

---

### T6: Dual-Layer Explanation (双层解释)

**When:** 想学习/理解一个概念，特别是技术性强的内容。

**Template:**
```
请用两个版本来解释 [概念名称]：

**版本一：大白话版**
用最生活化、最通俗的方式解释，就像在给一个没有任何专业背景但很聪明的人聊天。用生活中的比喻和例子。

**版本二：专业版**
用该领域的专业术语和框架来解释，面向有一定基础的从业者。包含关键术语的精确定义。

最后，列出两个版本之间的"认知差距"——从版本一到版本二，需要额外理解哪些关键概念？
```

**Key:** 通俗版追求生活化而非幼稚化（可以用"洗脚城大爷能听懂"作为心理标尺）。对照学习比单一版本更利于深入理解。

---

### T7: Output Shaping (输出塑形)

**When:** 知道要问什么，但需要控制 AI 的输出格式、结构或长度。

这不是一个独立模板，而是叠加在其他心法或基础优化之上的约束层。在生成 prompt 时，检查用户是否有以下需求并补充：

- **格式指定**：表格、编号列表、JSON、代码、Markdown、对话体
- **长度控制**："用 3 句话概括"、"不超过 500 字"、"写一篇 2000 字的长文"
- **结构约束**："先给结论，再展开论证"、"按优先级排序"、"分 pros/cons 两栏"
- **语气/风格**："正式书面语"、"口语化"、"技术文档风格"
- **排除项**："不要用比喻"、"不要列优缺点"、"跳过基础概念"

**Key:** 大量 prompt 效果差不是因为问错了问题，而是没告诉 AI 答案该长什么样。

---

### T8: Chain Decomposition (任务链拆解)

**When:** 用户扔来一个大任务（"帮我写商业计划"、"帮我做竞品分析"），直接执行会导致输出质量低或遗漏。

**Template:**
```
我需要完成这个任务：[任务描述]

请你不要直接开始做。先帮我把这个任务拆解成 3-7 个有序的子步骤，每个步骤：
1. 明确的输入和输出
2. 完成标准（怎样算做好了）
3. 预估的交互轮次（1轮还是需要追问）

拆解完成后，我们按顺序逐步执行。在已授权范围内连续完成各步骤；只有缺少决定性信息或需要新增授权时才暂停。
```

**Key:** 拆解后的每一步可以单独套用其他心法（如 T1 选角色、T2 追问细节），质量远高于一步到位。

---

## Combination Patterns

| Combo | When | Flow |
|-------|------|------|
| T1 + T2 | 复杂专业咨询 | 先选角色，再以该角色身份追问 |
| T2 + T4 | 方案制定 | 先追问了解全貌，再预演失败 |
| T5 + T1 | 复刻专业内容 | 先反向提示得到 prompt，再加角色提升专业度 |
| T2 + T3-B | 信息不足的复杂决策 | 先补齐会改变结论的信息，再做双向钢人比较 |
| T3-B + T4 | 重大决策 | 先比较选项并形成暂定判断，再对选中方案预演失败 |
| T6 + T2 | 深度学习 | 先双层解释入门，再追问深挖不懂的点 |
| T8 + 任意 | 大型任务 | 先拆解步骤，每步按需套用其他心法 |
| 任意 + T7 | 格式敏感 | 任何心法都可叠加输出塑形约束 |
