# Yahoo Finance：内置浏览器读取

macro 中的 Yahoo Finance 数据通过当前宿主的内置浏览器访问官网。在 Codex 使用 `mcp__cua_repl.js` 控制 `iab`，遵守工具初始化要求；其他宿主无内置浏览器时说明不可用。本规则覆盖 macro 中的 Yahoo 页面读取，不改变其他子插件的数据路线，也不把 Yahoo 引入原本无需它的任务。

## 入口

| 指标 | 代码 | 页面 |
|---|---|---|
| CBOE Volatility Index | `^VIX` | https://finance.yahoo.com/quote/%5EVIX/ |
| US Dollar Index | `DX-Y.NYB` | https://finance.yahoo.com/quote/DX-Y.NYB/ |
| S&P 500 | `^GSPC` | https://finance.yahoo.com/quote/%5EGSPC/ |

优先复用已知标签页；新建时可调用 `await cua.createBrowserTab("iab", "https://finance.yahoo.com/quote/%5EVIX/", { visible: false })`。仅采集时保持后台，用户要求展示时再显示。其他标的从已核实的官网链接或站内搜索进入，核对名称、完整代码及市场；不猜代码对应关系。

## 读取与口径

1. 从主标的标题和对应报价区域读取名称、代码、市场/来源标签、指数点位或价格、绝对变化、涨跌幅、`Previous Close`、`As of` / `At close` 的时间及原时区、`Market Open` / 盘前 / 盘后等状态、实时/延迟标签。使用可访问性树，必要时根据已观察的 DOM 或截图定位。不要误取顶部行情条、侧栏、广告、新闻或相似标的数值；操作后刷新页面状态再定位。
2. 行情时间、交易日期和抓取时间分别记录。页面仅显示时分秒时保留原文，不擅自补成用户本地“今天”；需要交易日期时用页面历史表等证据核实，无法确定就注明日期未提供。保留 EDT/EST/CDT 等实际时区，不统一硬写 EST。`Market Open` 不代表实时，未显示实时/延迟标记就写“页面未说明”，不能把刷新时间当行情时间。
3. 标普 500 指数 `^GSPC` 不得替换成 SPY ETF 或 ES 期货；DXY `DX-Y.NYB` 不得替换成美元指数期货、ETF 或 FRED 广义贸易加权美元指数。页面显示 USD 时仍须区分指数点位与可交易资产的美元价格。Yahoo 的 VIX 页面不是 VIX 期货，也不是 CNN 恐惧贪婪指数。
4. 周/月变化进入可见的 **Historical Data**，读取日期、频率和同一列历史值，不凭图形估算或把 `1D` 涨跌当周变化。保留 `Close` 与 `Adj Close` 的口径，不能混用；指数价格变化不冒充含分红总回报。若交易仍在进行，当日历史行的 `Close` 可能随盘中报价更新，不能当最终收盘。默认“周变化”为最近两个已完成交易周最后交易日 Close 的变化；用户指定近 5 个交易日、自然周或本周至今时采用指定范围，明确起止日期及是否包含盘中值。计算 `(末值/初值 - 1) × 100%`；缺少任一端点就写无法计算，不补零、不静默改日期。
5. 晨报区分前一交易日收盘表现、当前盘中、盘前/盘后和期货行情；不把普通日涨跌或上一交易日 Close 写成精确“隔夜”区间。日历/新闻若读取 Yahoo 的事件或文章，保留实际事件/发布时间、原始来源及预计/确认状态；公司事件日期与业绩按[IR 核验规则](company-ir-browser.md)回到官方公告/披露核验。本次入口验证不代表全部财报/新闻字段均可读取。

## 输出与失败处理

- 每项输出附官网 URL、名称/代码、数值及单位、报价时间/交易日期、原时区、市场状态、实时/延迟标签和抓取时间；历史变化另附起止日期、原始值及计算口径。字段没显示就注明未提供，`--` 等缺失值不能记作 0。
- 普通促销弹层可关闭；数据区域未加载可刷新或重开内置标签页一次，仍失败则标记“未获取”及具体原因，保留其他成功项。登录/订阅限制无法读取的内容标记受限，不注册、试订阅或填写 Key。
- 不自动回退外部 Chrome/CDP 脚本、Yahoo API、yfinance、隐藏接口、WebFetch/curl 或搜索摘要获取 Yahoo 数值；更换为 Cboe/FRED 等来源须用户另行指定。此访问路径无需 API Key，不承诺无限访问或无延迟。
- macro 当前加密价格仍只走 CoinGecko + Binance 双源规则；忽略 Yahoo 页面附带的 BTC/ETH 行情，不作为第三源或失败兜底。CNN、FRED、DefiLlama 和 CME/Polymarket 各自遵循原规则。
