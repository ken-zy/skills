# 美联储 FOMC：内置浏览器读取官网

macro 引用 FOMC 会议日期、已公布政策、会议纪要或经济预测时，通过宿主内置浏览器访问美联储官网。在 Codex 使用 `mcp__cua_repl.js` 控制 `iab`，遵守工具初始化要求；其他宿主没有内置浏览器时说明不可用。普通新闻不涉及这些事实时无需额外读取。

## 入口与流程

1. 从官方日历 `https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm` 开始。优先复用标签页；新建示例：`await cua.createBrowserTab("iab", "https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm", { visible: false })`。仅取数时保持后台，用户要求展示再显示。
2. 按用户指定年份/会议定位；未指定时，下一次会议从最新日历选择尚未结束的会议，最新文件按其实际发布日期选择。核对年份、跨月日期、星号对应的 SEP 标记和暂定日期说明，不把固定月份、缓存链接或旧会议永久当“下一次”。查询当前政策还须留意官网已公布的临时决议，不能仅凭最近常规会议断言当前利率。
3. 在该会议区域沿实际链接打开 **Statement**、**Minutes**、**Projection Materials**、**Implementation Note** 或 **Press Conference**。优先 HTML / accessible version；不按日期猜文件 URL。读取可访问性树，必要时使用可见 DOM 或截图；操作后重新获取页面状态。
4. 分别记录会议起止日期、文件类型、标题、实际发布日期/时间/原时区、页面更新时间（若有）、URL 和带时区的读取时间。日历的 Last Update 不是每份文件的发布时间；纪要正文的会议日期不是纪要公布日。只有日期时不补小时；未给时区不猜，换算北京时间时核对夏令时并保留原始时间。

## 各材料的口径

- **会议日历**：保留美国会议日期和计划/确认状态；星号仅表示附带 SEP。日历有会议不代表声明、纪要或预测已发布。按日历实际链接核对发布状态，缺链接写“日历未列出，尚未核实发布”，不能自行宣称没有会议或用上一期冒充本期。若报告引用最近可得纪要，明确其所属会议；“三周后”只是常规安排，不能冒充官网已确认的精确发布日期。
- **Statement / Implementation Note**：读取目标利率区间上下限、政策动作及幅度、投票情况和重要措辞；需要生效日期或执行利率时核对 Implementation Note。25 bp = 0.25 个百分点，不是利率相对变化 25%。区分联邦基金目标区间、有效利率和其他执行利率；FRED 的 FEDFUNDS 月均值不能代替目标区间。
- **Minutes**：读取所属会议、发布日期和相关原文，区分工作人员评估、与会者讨论和委员会正式决定；不能把纪要里回顾的市场预期写成当前概率。与上一期对比时保留两期日期和原文依据。
- **SEP / 点阵图**：保留预测发布期、预测年份、单位以及 Median / Central Tendency / Range 列。GDP 和通胀按表下注释核对 Q4 对 Q4 口径；失业率通常为 Q4 平均；联邦基金利率预测为指定年末目标区间中点或目标水平，不是当前目标上限。读取 accessible 表格和脚注，不能将上期预测行当本期、将空单元格补零、凭图点像素编造数字。官员预测不是政策承诺、已实现值或市场概率，参与者人数也不是 FOMC 决议赞成票数。
- **Press Conference**：通过会议页面按需读取已提供的官方文字稿/材料，区分开场陈述、问答与正式声明；仅看到视频或材料链接不等于读过发言全文。只有 PDF/视频且当前浏览器无法读取时标明正文未获取。

## 输出与失败处理

- 日历输出会议日期、事件/材料类型、计划或发布状态、已核实的发布时刻及来源；政策摘要输出所属会议、文件发布时刻、目标区间/动作、事实与分析、原文链接及缺失项。预测单列发布期和预测年份，不能混入实际经济数据栏。
- 页面加载失败可刷新或重开内置标签页一次；仍失败明确“未获取/受限”，保留成功材料。页面没有某字段就说明未提供；未读到文件不等于政策未变。
- 不自动使用外部 Chrome/CDP 脚本、API、隐藏接口、curl/WebFetch 或搜索摘要替代官网事实；不静默换成媒体或 FRASER。普通新闻检索可用于找线索，但政策事实回到上述浏览器路径核实。本路径无需 API Key，不承诺无限访问。
- 市场加减息概率仍执行 [CME FedWatch + Polymarket 双源规则](fed-expectations-browser.md)，不把官方预测和市场概率合并。FRED 历史经济序列仍执行自身规则；本规则不改变其他指标来源。
