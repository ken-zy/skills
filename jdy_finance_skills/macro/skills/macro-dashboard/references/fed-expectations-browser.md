# 美联储利率预期：CME FedWatch + Polymarket

在 macro 输出美联储加息、降息或不变的概率时，两站都通过当前宿主的内置浏览器读取；CME 为期货隐含预期主来源，Polymarket 为预测市场第二信息源。不是首源成功即停止的 fallback。只列会议日历、转述已公布决议或普通新闻时不额外拉取概率。

## 入口与读取

- CME：[FedWatch 官方页面](https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html)。[方法说明](https://www.cmegroup.com/articles/2023/understanding-the-cme-group-fedwatch-tool-methodology.html)用于解释口径，不能替代页面当前数值。
- Polymarket：用户指定的 [2026 年 10 月会议市场](https://polymarket.com/event/fed-decision-in-october-20260617190323537)作为本次入口。不能永久把它当作“下一次会议”；每次核对年份、会议日期和市场状态。用户指定历史市场时保留历史范围，不擅自换期；默认当前预期则从页面的后续会议链接或站内搜索查找下一次未结束会议，重新读规则。找不到同次市场就标记未获取，不能改拿“全年降息次数”或“年底利率”作替代。
- Codex 使用 `mcp__cua_repl.js` 控制 `iab`，遵守工具初始化说明，优先复用已知标签页；仅取数时保持后台。新建入口示例：
  ```javascript
  const cmeTab = await cua.createBrowserTab("iab", "https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html", { visible: false });
  const polyTab = await cua.createBrowserTab("iab", "https://polymarket.com/event/fed-decision-in-october-20260617190323537", { visible: false });
  ```
  示例可拆成调用以符合首次初始化要求。读取可访问性树；必要时使用受支持的 DOM 快照或截图，再按可见控件操作。操作后读取新状态，不复用旧元素编号。其他宿主没有内置浏览器时明确说明不可用。

### CME 必读字段

选择目标会议的 **Current** 页，读取内嵌 QuikStrike 中的会议日期、当前目标区间 `(Current)`、全部可见目标区间、`NOW` 概率、`Data as of` 时间及原时区；有需求再取 `1 DAY / 1 WEEK / 1 MONTH` 对应日期与历史概率。首屏可能只加载外层介绍，须确认内嵌概率表已出现。不要把 Dot Plot、历史列、期货合约价格或倒计时当作当前概率。

保留 BPS 单位：375–400 bps 对应 3.75%–4.00%。`FEDFUNDS` 是月平均有效利率，不能用作会议前目标区间基准。页面无当前基准时，可通过内置浏览器读 [美联储公开市场操作页面](https://www.federalreserve.gov/monetarypolicy/openmarket.htm)核实；无法核实则不推算加减息幅度。涉及官网会议日历、声明、纪要或 SEP 时执行 [FOMC 官网规则](fomc-browser.md)。

### Polymarket 必读字段

读取市场标题、实际 URL、会议年份/日期、各结果完整名称和页面显示概率、市场状态、总成交量及可见的分项成交量；盘口流动性或买卖价差仅在页面能读到时补充，成交量不等于当前深度。展开/读取 **Rules / 规则**，确认目标利率上限还是其他指标、相对哪个时点变化、分档边界、舍入方式、结算来源、延期/无声明时如何处理。结算以每次实际规则为准；规则读不到时可展示已取得的报价，但标记“结算规则未核实”，不计算双源差。

该 10 月入口的规则按会议前后目标区间上限变化结算，包含非标准幅度向上取整至 25 bps、下一次会议结束前仍无声明则归“不变”等条款。不能把中文“50 个基点以上”自行解释为严格大于 50；以原文规则确定是否包含 50。页面本地日期标签可能与规则中的美国会议日期相差一天，须核对规则，保留原显示与时区信息，不能只按标题/月名配对。

概率取结果行显示值，保留 `<1%` 等精度；不把“买入是/否”的挂单报价、图表悬停历史值、背景文字或 FAQ 中的数字替代当前概率。结果行和图例可能不同步，应刷新一次核实，仍矛盾则注明页面内部不一致。保留原始概率，不为凑 100% 重新归一化；不得把 `<1%` 写成 0% 或根据买入价补出精确概率。

## 对齐与比较

1. 两站同批读取，各自记录含时区的抓取时间及网页数据更新时间。未显示更新时间写“页面未提供”，抓取时间不能冒充报价时间；同时展示 CME 数据距抓取的时长。两源未证实同步、明显延迟或跨重要消息时，只作为带时间的页面快照，不能声称实时一致/背离。若采集过程中某源明显更新，重新读取另一源一次，仍不同步则保留限制。
2. 核对同一次 FOMC 决议和同一结果集合。CME 是会议后目标区间的无条件分布，Polymarket 常是该次会议相对会议前的变化。只有下一次会议、会议前目标区间已知且没有未处理的中间政策变化时，才按目标区间平移映射到当次加减息幅度；披露会议间临时调息等口径风险。较远会议不能拿 CME 的累计变化当作该场会议的变化，也不能用两个边际分布相减推出单次动作概率；无等价口径则只并列原始数据，写“不可直接比较”。
3. 按实际结果分档，例如降息 ≥50 bp、降息 25 bp、不变、加息 25 bp、加息 ≥50 bp。大档 CME 概率需汇总其覆盖的全部目标区间，不能把单一 50 bp 档当成 ≥50 bp；缺行不能补 0。也不能把 CME 的 HIKE 总概率直接对比 Polymarket 的“加息 25 bp”。映射不完整、特殊结算规则影响等价性时标记不可比。
4. 可比且精度足够时计算 `差异（百分点）= Polymarket 概率(%) − CME 概率(%)`，保留方向；未知更新时间时只能称“页面快照差”，并附时间限制。`<1%` 等区间值不输出伪精确差，可保留区间或写无法精确计算。不同源不求平均、不合成一个“真实概率”，也不把差异称为套利收益。
5. 本规则默认展示差异，不套用加密行情的 1% 价差告警。若用户指定利率概率分歧阈值，以**百分点**执行；仅在语义与时间均可比时判断，其他情况提示未完成核验而非“无告警”。两源都代表市场定价，不是美联储官方承诺。

## 失败与边界

- 每源都尝试，成功数据可保留。加载/崩溃异常可刷新或新开内置标签页重试一次，仍失败则标记“未获取”；缺少规则、日期、结果或状态核实所需信息时标记“未完成核验”，不能说双源验证通过。
- 市场已结束/已结算的数据只能当历史结果，不作为当前预期。概率为 0/100、页面有买入按钮或存在成交量，都不能单独证明市场仍在交易；状态不明确时标注未核实。
- 不回退外部 Chrome、CME/Polymarket API、隐藏接口、curl/WebFetch 或搜索摘要取概率；不注册、连接钱包或下单，此流程无需 Key。
- 本规则仅替换美联储政策概率路径，其他经济指标、加密价格和 DefiLlama 的已有规则保持各自适用范围。
