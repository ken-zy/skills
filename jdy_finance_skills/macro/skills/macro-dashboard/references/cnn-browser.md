# CNN Fear & Greed：内置浏览器读取

macro 引用 CNN 美股恐惧贪婪指数时，通过当前宿主的内置浏览器读取官网。在 Codex 使用 `mcp__cua_repl.js` 控制 `iab`，遵守工具初始化要求；宿主没有内置浏览器时说明不可用。新闻/日历不涉及情绪指数时无需额外读取。

## 入口与读取

- 官网：`https://edition.cnn.com/markets/fear-and-greed`。优先复用标签页；新建可用 `await cua.createBrowserTab("iab", "https://edition.cnn.com/markets/fear-and-greed", { visible: false })`，用户要求展示时再显示。
- 从主标题 **Fear & Greed Index** 对应的 Overview 区域读取 0–100 分数、情绪标签、`Last updated` 日期/时间/原时区，以及 `Previous close`、`1 week ago`、`1 month ago`、`1 year ago` 的比较值。先用可访问性树，正文缺失时读取可见 DOM 或截图；操作后刷新状态再定位。顶部行情条、新闻、图表坐标轴和七项子指标不能冒充主指数。
- 各字段分别记录来源 URL、页面时间及带时区的读取时间；网页未提供年份或精确历史日期时保留原文并注明缺失，不能用本地日期或简单减去 7/30/365 天补齐。读取时间不是数据更新时间。
- 按需读取七项组成及各自更新时间，不能用其中一项的时间替代主指数时间。仅有曲线时不凭像素估算历史数值；历史比较卡片保留页面给出的相对期间标签。

## 口径与输出

- 明确写作“CNN 美股恐惧贪婪指数”，范围 0–100。引用页面情绪标签，缺失则写“标签未获取”，不自行猜测分档边界；它不是加密恐惧贪婪指数，也不是上涨概率。
- 变化使用“指数点”：例如当前 32、前收盘 33，写下降 1 点；不能写下降 1 个百分点或混称隔夜变化。保留比较期间，盘中值不能当最终收盘。
- CNN 七项指标等权形成综合指数，不是七个不同单位原始值的直接平均，也不是投资者问卷。分析时用于情绪背景，不单凭极端读数断言反转。
- 输出示例字段：来源链接｜分数/100｜页面情绪标签｜页面更新时间及原时区｜读取时间及其时区｜前收盘及点数差｜可选历史比较值｜缺失/受限状态。

## 失败处理

- 数据未加载时可刷新或重开内置标签页一次；仍失败则标明“未获取”及原因，保留已成功的其他数据。缺失字段不补 0、不当“中性”；只读到正文说明不代表读到最新指数。
- 登录、订阅或条款阻挡时按宿主确认规则处理；无法继续则标记受限，不自动注册、订阅或接受协议。
- 不自动回退外部 Chrome/CDP 脚本、CNN 隐藏接口/API、WebFetch/curl 或搜索摘要获取数值；也不静默换成 AAII、VIX 或加密情绪指数。浏览器路径无需 API Key，不承诺无限访问或持续可用。
