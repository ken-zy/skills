# macro 网站来源统一访问规则

适用于 macro-dashboard、catalyst-calendar、morning-note、news-digest 及对应命令。现有和后续新增的网站来源统一通过内置浏览器读取，包括 Medium、Discord 网页版、财经媒体、项目博客/文档、治理论坛、日历、交易所公告及监管网站；无需逐个来源另行确认访问方式。其他子插件不受本次修改影响。

## 网站与非网站路径

- 网站正文、数据表、公告和网页附件：Codex 使用 `mcp__cua_repl.js` 控制 `iab`，遵守初始化要求，优先复用标签页、后台读取。其他宿主缺少内置浏览器时报告不可用。各来源既有专用规则继续约束身份、口径、时间、双源比较及失败处理。
- 搜索仅发现候选和链接；读取原文后才引用事实或数值。禁止以搜索摘要、外部 Chrome/CDP、WebFetch/curl、隐藏接口或临时安装的抓取器代替网站读取。链接卡片、摘要和下载链接不代表已读全文。
- 保留已授权的非网页路径：[CoinGecko + Binance 插件](plugin-market-data.md)获取行情/项目信息及新闻线索，[DefiLlama 免费 API](defillama-free-api.md)获取结构化指标。这些服务有官网并不意味着其插件/API 要改成浏览器；插件新闻中的文章链接仍按本规则读取。新增 API/MCP、RSS、机器人、邮件或链节点不因网站访问授权而自动接入。

## 读取与证据

1. 从官网、已核实账号或可信原始链接进入目标页面，检查作者/机构、项目身份、年份和目标事件。优先读取原文；转载、同一项目的多平台副本不能当独立信源。
2. 实际读取正文及相关表格/附件，保留 URL、作者/发布机构、发表或更新日期、数据期间/事件日期、原时区、单位/口径及读取时间。动态页面操作后刷新状态；截图仅补充可见内容，不能恢复被遮罩的付费内容。PDF/图片/视频无法读取时按实际可读范围报告。
3. Medium 核对作者与 Publication（专栏）及官网关联；只见预览则标全文受限，不能把社区文章当官方公告。已由作者/官方分享的合法免费链接可使用，不绕过付费墙。
4. Discord 网页版仅查看当前账户已可访问、与任务有关的服务器/频道；用项目官网链接核对服务器身份，保留消息链接、作者/角色、时间及编辑/上下文。社区用户发言不等于团队公告。邀请页不代表已读频道，不自动加入服务器、申请权限或发送消息。
5. 媒体报道区分事实、引述、分析与传闻，重大结论尽量回到公告/监管文件/项目原始资料。保留更正及未解决冲突；未找到或访问受限不等于没有事件。发现同一事实另有可访问原文时可明确换用该来源，不冒称原站已读；专用规则限制换源的仍按其约束执行。

## 不可用时

普通加载失败可刷新或重开内置标签页一次；登录墙、验证码、付费或权限限制不反复尝试。沿用现有授权会话；需要用户操作时说明具体页面和缺口，不索取秘密、不自动订阅。保留其他成功项和未核实状态；不能承诺全部网站、全文或历史内容都可读取。

本规则只改变访问路线，不启动持续监控、订阅通知、关注账号或对外发布，也不更新已安装插件缓存。每次引用以实际读取结果为准。
