# 领导晨报：覆盖先于编辑

仅用于明确要求给领导汇报或无报价的晨报；普通无报价新闻摘要不触发。此文件替代 morning-note / morning 命令的通用 Workflow、输出模板、财报表格、交易想法与冲突检查项；通用任务继续原流程。用户和当前任务的范围优先。

## 本模式边界与来源

不采集或展示代币现价、历史价、价格涨跌幅、走势、换汇率或双源价差；跳过 CoinGecko 当前/历史行情、Binance 价格、换汇与行情健康探针，不从浏览器、搜索摘要、直接 API 或旧报告补价。未采集的报价不是缺口。不汇报美股指数点位，不为展示单独采点；方向和强弱足够时不取额外幅度。数字只在解释核心变化时保留，不堆原始指标。不推断持仓，不给交易指令，不进行交易或对外发送消息。

网站正文和数值遵循[内置浏览器规则](../../macro-dashboard/references/web-sources-browser.md)，搜索仅发现链接。新闻页优先读取文章正文及必要标题/日期，排除行情栏、ticker、相关推荐；意外可见报价不记录、不复用、不展示，不把整页输出作为无报价取数捷径。

CoinGecko 新闻仅用当前用户指定连接（身份在任务配置中，不能仅凭前缀确定），调用前读取[共享调用与失败规则](../../macro-dashboard/references/plugin-market-data.md)。同次新闻批量返回复用；每个逻辑请求首次加一次追加的预算、错误优先级、共同等待与会话停止保持有效，新闻模式不先启动行情计时。会话终止立即停止该连接新请求；仅宿主实际提供已授权合规重连能力时恢复，不能声称不存在的重连。新闻失败可由内置浏览器读取其他可信原文，不换 CoinGecko 连接，不把失败当无新闻。只返回所需 structuredContent 普通字段，不输出原始 CallToolResult、_meta、资源/模板/HTML/图片，不调用展示工具。宿主强制渲染无法抑制时如实说明。

## 先覆盖，再筛选

先设 Asia/Shanghai 日期与截止时间。窗口为上一期有效截止时间至本期；无法取得上一期时默认近 24h，内部记录该选择。每个核心类别至少尝试一个与窗口相关的可信来源，按事件日期核验，不能为省正文跳过扫描。综合页面可复用，但只覆盖其实际出现并核验的类别。某类无法读取时最多换一个合理且合规来源；仍失败记缺口，不无限调用或用搜索摘要补正文。按时输出当期简报，核心结论与缺口相称；无宿主取消能力时不承诺严格墙钟超时。

六个核心类别与发现入口：

| 类别 | 必查范围与入口 | 原文补证 |
| --- | --- | --- |
| 宏观与股债环境 | 目标窗口的可信市场复盘、官方经济/政策发布线索；保留股债方向差异 | 数据发布机构、[FOMC](../../macro-dashboard/references/fomc-browser.md)；引用 Yahoo 时执行其[规则](../../macro-dashboard/references/yahoo-browser.md) |
| 重要公司/行业 | 可信财经新闻中的重要经营、财报、并购或行业变化线索 | 有候选再读[公司 IR / 正式披露](../../macro-dashboard/references/company-ir-browser.md)，不固定罗列个股 |
| 能源与地缘 | 可信综合新闻、能源机构/政府当期动态 | IEA、政府或措施原文，区分宣布、供应恢复与实际执行 |
| 加密监管及行业资金新闻 | 可信加密/财经新闻或监管机构动态，必须包括重要 ETF / 加密资金新闻线索扫描 | 监管原文；有流量线索或主线需要再读 ETF 明细 |
| 协议安全/运营 | 可信加密新闻中的安全、退出、升级等重要线索 | 项目公告及实施证据；引用官方 X 时执行[身份核验规则](../../macro-dashboard/references/official-x-browser.md) |
| 今日及下一交易日事件 | 官方经济/政策日历、重要公司/行业日程线索 | 官方机构与 IR 确认，区分预计/确认和发布/会议时间，转北京时间 |

每类内部记录状态、实际来源链接、已检查时间范围与候选结论：checked 表示指定来源/窗口已检查，不表示全领域穷尽；partial 表示部分窗口/材料可读；unavailable 表示必要材料失败且允许的一次换源也无法完成；not_applicable 仅用于确实不适用的补证来源，不能给本模式六类套用以跳过必查。

重要 ETF 新闻发现属于上述核心行业扫描；初始没有 ETF 候选也要完成这个入口检查。未发现线索须以实际扫描为基础，不能未经检查记 not_applicable；扫描受限记 partial / unavailable。发现候选后决定是否补流量明细，核实但未入正文也留排除理由。

条件补证与扫描分开：历史序列/比较才读 [FRED](../../macro-dashboard/references/fred-browser.md)；引用利率概率才读 [FedWatch + Polymarket](../../macro-dashboard/references/fed-expectations-browser.md)；引用情绪指数才读 [CNN](../../macro-dashboard/references/cnn-browser.md)；重大解锁线索才读 [Tokenomist + DefiLlama](../../macro-dashboard/references/token-unlocks-browser.md)；项目公告引用官方 X 时才读其核验材料；异常或核心论证确需时才按[免费 API 规则](../../macro-dashboard/references/defillama-free-api.md)取 DefiLlama 非报价指标或浏览器 ETF 流量明细。未触发这些补证记 not_applicable，不声称已经检查。保留观测日期，日频/24h 不是精确隔夜，TVL 不是净流入。

CoinGecko 最新十或二十条只是线索。聚合内容未覆盖窗口或被预测/推广淹没时，浏览器补查缺失类别，不能反复扩大插件调用、把最近批次当全市场覆盖。

## 候选到主线

候选内部保留事件日期、发布日期、统计期间/交易日、原文、证据等级（官方/媒体转述/未核实）、实质新进展或既有背景、选入/合并/排除理由。记录默认在本次运行上下文，不新增持久系统；仅用户询问来源/遗漏时简洁展示。编辑排除不等于漏采。

按影响范围、时效性、可信度排序，先选最重要主线，再在已核实候选中检查会改变判断的反证。不能只写托管放宽而遗漏同窗口准入诉讼，或只写股涨而遗漏融资压力。没有读到的反证不补造；重要覆盖缺口存在时不下全面判断。

相关消息合并仍保留方向和口径：不同 ETF 流向不能概括全面流入；单家公司改善不能推断全行业复苏；一例资金追回不能推断行业安全恢复；提案、宣布、实施中不能写已生效或兑现。事实、媒体转述、分析和未知用措辞区分，不机械贴标签，不强行归因。

转载的新发布时间不重置事件日。旧事件仅有实质进展或对今日判断不可缺少时入选，并标旧背景。周末/休市写最近交易日，旧收盘需要时一句带过，不冒充当天。无新增不凑三条；只能在实际检查的来源/窗口内称未发现重大新增，访问失败不得写无新闻。

## 成文和发送检查

通常 400–600 字、两分钟可读；信息少时更短。开头 H1 写北京时间日期与截止时间。H2 依次为今日结论（1–2 句）、重点变化（最多三条）、今日关注（1–2 项）。每条重点 H3 写“一、主题”等，再另起普通段落说明发生什么、为何重要及可能影响。无重点或无固定催化时简短说明，可写下一项已核实重要事件，不能用泛泛关注凑栏目。缺口仅在影响核心判断时末尾一句说明。

报告允许的 Markdown 仅 H1/H2/H3 标题和可点击来源链接。标题标记后一个普通空格，前后空行，正文另起普通段落；标题通过标题语法放大/加粗，正文不强调。禁止星号、下划线强调、反引号、代码块、列表、表格、图表、图片、sparkline、交互卡片、可视化、widget、HTML、嵌套分栏。此限制针对最终晨报，内部记录和本规则文档可以用表格。链接紧邻重点或末尾注明事项，不在晨报解释排版。

发送前确认：六类均有实际扫描记录；候选日期/统计期/官方状态核验且旧背景清楚；条件补证未检查不冒称通过；已检查主线反证且方向差异保留；无禁止报价或点位，未执行交易/外发；核心结论与缺口相称；标题空格/空行与来源链接正常，正文无禁止格式。每个计划时点都输出，不逐次要求确认；定时运行不修改 skill 仓库。
