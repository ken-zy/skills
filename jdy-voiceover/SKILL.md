# 本机配音

统一入口 `/Users/jdy/Code/voice-studio/voice`，先读项目 `AGENTS.md` 与 `README.md`。不复制环境或模型。自行维护的本技能位于 `/Users/jdy/Documents/skills/jdy-voiceover/`，原发现入口使用软链接。

## 当前认可方案与边界

2026-11-04 用户认可：**按语义分段、每段不超过30秒、固定本人原始参考音和 Hi-Fi 提示、不回灌生成结果、拼接后温和缩短停顿**。用户反馈缩短停顿版自然、没有嗡鸣；这是本次样音的听审结论，不保证新文案自动通过。

本流程取代旧的“日常旁白单次连续生成”制作约定。CLI 不加参数时仍是旧声线 B 连续生成，因此必须显式传入下面的制作参数；不能把更新技能说成已经修改 CLI 默认。历史连续生成基准保留，不覆盖。mini／MLX 路线不恢复。

文案修改、事实核对和确认由所属内容项目负责；Voice Studio 接收已确认稿并负责声音制作。本人的参考录音与私有日志不上传；不授权发布或替换已认可成片。

白板笔声／混音另读 [柔和笔声预设与交付](references/whiteboard-pen.md)。2026-11-05 用户已确认该方案并明确要求后续白板复用；使用固定素材与预设，不重新试遍音量或套回被否定的密集碎笔声。它是声音 skill 的辅助脚本，不是 `voice speak` 新增能力。

## 1. 接稿与语义分段

- 保留最终原文和哈希，检查数字、年份、人名、多音字。表达不清或必须改字时交回内容项目，不为时长擅自删改。
- 按完整事件或意思组织段落，在自然转折或句末切分；**不要逐句机械生成，也不要按等字数硬分**。
- 估算时留余量，通常以20–25秒以内为起点；生成后逐段测量，**实际最长30秒**。超时段重新按语义拆分，只重做受影响段落，不加速、不截断。
- 总时长由自然表达决定，不强行凑90秒。文案及导出文件存放在所属项目的新目录；运行记录与私有资产留在 Voice Studio。

## 2. 固定声音条件，逐段独立生成

使用现有锁定的 VoxCPM 2.0.3 / VoxCPM2 权重 revision `32279effe8c19989596f05d353d1447f51d9e915`、PyTorch / MPS / float32，不另装依赖。

每段使用相同的本人原录音 `ref-02`，同时作为 reference 和 Hi-Fi prompt；逐字稿使用已登记确认文本。CFG 2.0、10步、seed42、max_tokens2000、min_len2，关闭 normalize、retry_badcase、denoise、optimize，无风格指令。

逐段调用（路径替换为调用方项目的实际绝对路径；导出目录必须不存在，其父目录须存在）：

```bash
/Users/jdy/Code/voice-studio/voice speak \
  --input /调用方项目/配音任务/part-01.txt \
  --output-dir /调用方项目/配音任务/part-01 \
  --reference ref-02 --mode hifi --style "" \
  --seed 42 --cfg-value 2 --inference-timesteps 10 \
  --min-len 2 --max-tokens 2000 --no-normalize --no-retry-badcase \
  --trim-end-ms 0 --fade-out-ms 0 --tail-ms 0
```

- 执行前可用同样参数加 `--dry-run` 核对；检查各段 reference、prompt、逐字稿哈希和推理参数一致。
- **不将上一段生成音频或潜变量作为下一段提示，不调用无限追加历史的缓存合并，不使用逐句 bounded-continuation 实验模式。**
- 不用历史合成样音悄悄替换本人原始录音。更换参考音、提示音、模型、精度或风格须作为新候选听审，不覆盖本方案。

## 3. 原音拼接与收尾

保留每段原始音频与参数；按原文顺序拼接同采样率 PCM，不逐段追加800ms留白。保留模型已有停顿，不默认交叉淡化、均衡、降噪或响度归一化。

仅全文最后淡出12ms并补800ms留白，不裁尾。旧样音240ms裁尾不作为通用规则。拼接原版和后续停顿处理版分别保存。

## 4. 温和缩短长停顿

直接处理音频，不重新生成，不变速、变调或调增益。沿用用户通过的处理参数：

- 用10ms帧筛选低音量区：RMS低于−50 dBFS，峰值低于−42 dBFS。
- 只处理持续至少450ms的低音量空白，从中间缩短约30%，每处最多约250ms。
- 两端各保留至少100ms；短停顿不动，保留开头300ms和全文末尾至少1秒。
- 切点可在约±2ms范围移到接近零幅度的采样，避免点击；不改变保留下来的采样，不对语音做交叉淡化。
- 低音量不必然是静音。结合气口、轻声和上下文判断；有呼吸、尾音或词内闭塞风险时跳过，不为压时长硬删。
- 记录所有删除区间和原音到成品的时间映射；校验保留下来的PCM与原版完全一致。

已认可实现与证据可只读参考：`/Users/jdy/Code/voice-studio/.local-voice/experiments/semantic-pause-trim-20261104-v1/shorten.py`、`params.json`、`manifest.json`。脚本绑定旧样音，不直接复跑到已有目录；新任务使用独立路径。该样音从113.92秒减至107.13475秒，不能把这个缩短量当作所有文案的目标。

## 5. 验收与交付

- 自动检查原文覆盖、各段≤30秒、解码、有限值/削波、源文件哈希、拼接次序、保留PCM一致性。转写发现疑点时局部复核，不把ASR错字直接当发音错误。
- 听审全文，重点检查接缝的音色/语气/响度、后半段嗡鸣或异常加速，以及删停顿后是否抢话、吞气口。
- 频谱、音高和波形指标仅作辅助，不把技术检查写成听审通过。无法直接听辨时如实说明，并提供完整音频、接缝片段和末尾试听片段。
- 只修复问题段落或停顿；无新依据不重复已做过的长短、CFG或递归续写对照。
- 导出至调用方项目新目录，包含完整WAV/MP3、原文、参数、时间轴、哈希和检查记录；保留原音。每次新内容默认“待听审”，只有用户确认后标记通过。

本次认可的生成基准在 `semantic-fixed-20261104-v1/`，自然节奏基准在 `semantic-pause-trim-20261104-v1/`（均位于上述私有 experiments 目录）。文案优化与配音交接不等于发布授权。

## 6. 已确认旁白的白板混音

- 优先复用 [whiteboard-pen-soft-v1](references/whiteboard-pen.md)，只修改笔声分量；不重配、滤波、变速、变调或自动归一化已确认的人声。
- 接收真实触笔区间，短细节可以静音，提笔必须静音。先交付同一视频片段的原版／修订版声音对照；复用相同预设、素材和已确认音轨时不重复选声。
- 交付独立笔声、完整混音、参数、来源哈希与验证。AAC等有损编码前，用整数PCM验证 `混音−笔声=原旁白`；编码后的解码、峰值与音画同步另查。数值通过不替代听审。
