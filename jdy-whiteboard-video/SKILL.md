# 手绘白板故事视频

讲清故事，保留确认图稿的结构与细节，让画面随旁白逐步建立。本 skill 负责文案、图稿、语义笔顺、手部、字幕、音画对齐与视频封装；人声、音效、配乐、混音及其质量问题统一交给 Voice Studio。

## 开始与继续

1. 读取用户提供的内容、已有本集文件和最新审核意见。内容以用户提供的为准，默认不另查资料或核查事实；用户明确要求时补查。截图或文章中的第一人称不自动归到用户身上。
2. 新集使用独立目录：`python3 <skill目录>/scripts/init_episode.py --output <新目录绝对路径> --title <标题>`。它只初始化文件，不联网、不生成音视频、不选定声线、不安装软件，拒绝覆盖已有目录。项目已有 `docs/videos/` 时沿用该惯例。
3. 继续已有集时，读取 `episode.json`、旁白、镜头表及具体版本的审核记录。用户只要求某一步时完成该步，不扩大到后续阶段。旧故事重跑先核对实际成片使用的旁白、朗读输入与字幕来源，不把数字读法转写当作故事改写。
4. 已定稿／暂定定稿目录只读，修订另建同级版本。项目有 `docs/videos/PROTECTED.json` 时先读取并核对所列哈希；禁止在受保护目录原地运行渲染、混音、预览或语音脚本。清单损坏或悬空时保护状态未知，停止相关写入并报告。清单不由 Agent 擅自修改，详见 [工程参考与保护](references/reference-engine.md)。

## 已确认的制作规则

- 默认浅暖底、少量黑蓝橙线条、画面累积、带持笔手。1080p／30 fps可作继承值，用户另定画幅时按其要求。减少装饰不等于把人物与物品简化成粗糙几何形。
- 每个首次呈现的人物、物品和画板标记，都先有 imagegen 最终态草稿，经用户确认后再制作笔画；简单日历、箭头、数字也不跳过图稿确认。同款已确认版本直接复用，不重复生图或询问。角色身份、脸型、五官、衣领、头发、辫根、辫子、服装和道具特征必须保留。审核页显著展示全部相关人物，不能把图稿藏在折叠区后当作已完整交付。
- 按具体确认图稿提取并组织笔画，登记来源、裁切区域、哈希及审核证据；完成帧与来源比对，不另画一套简化造型。画板内容首次出现须逐笔绘制，不以整图淡入、扫出或末帧贴完整图补漏。已画内容回看时可保留。
- 笔顺按语义安排：人物先可辨主轮廓，再五官与特征；物品先主要结构，再细节；数字逐字完成并安排字内笔顺，不沿字外框描边。骨架和就近排序只能辅助定位，不等于真实笔顺。箭杆、箭头和强调线顺着主线画完，不反复回描或用碎线补画。
- 落笔时手与笔尖可见并跟随出墨端。停笔等待、跨区域或长距离换位时可收起手和笔，下一笔需要时再出现；不要用悬空移手填等待。手部不能遮字幕，前臂不得留下突兀截口；不要为藏截口新增字幕底栏。样片从首个受审对象第一笔之前开始，不能把礼帽等物品画完才截入。
- 字幕后期独立烧入，不由生图或ASR编写，也不进画板对象表。默认苹方 SC Regular、无描边、无底栏或分隔线，深色文字直接叠在浅暖画面底部；1080p参考字号46px，其他画幅按实际输出验证。显式选择简体字形，字体集合不能靠默认索引猜测。标题、人名和关键词作为画板内容仍须逐笔写。
- 用户先确认完整旁白，再按实际验收音轨排时；画面排不下先减少对象／细线、拆镜头或调整绘画速度。白板侧不调速、变调、降噪、改变声音风格或自行混音来迁就画面。

## 十步制作与审核

| 步骤 | 实际产出 | 用户审核 |
| --- | --- | --- |
| 1 定旁白 | 完整分段文案；前5秒具体场景或冲突；末尾约5秒自然互动问题；无卖书、购买或下单引导。旧故事优先最小修改 | 新稿／正文实质变化确认 |
| 2 画面规划 | 每段对象、顺序与含义；用 `\|` 标字幕节拍；旁白逐句写入 `storyboard.csv`，时间留空 | 自动 |
| 3 最终态图稿 | 全部人物、物品与标记的图稿及来源对应；新对象集中提交，已确认版本复用 | 确认具体版本 |
| 4 调用声音 | 通过 `jdy-voiceover` 调用 Voice Studio，显式传入该项目已记录的声音配置；接收完整旁白、实际输入、参数、清单与时长；不预设B或自然版 | 完整新音轨听审；短样确认不代替全文 |
| 5 词时间对齐 | 对验收旁白运行 `align_words.py`，得到 `word_timings.json`；强制对齐不能检测错读 | 自动 |
| 6 排镜头表 | 按实测时间排旁白／对象行并检查；调整 `\|` 后确定字幕断法。声音需改变时返回 Voice Studio | 自动 |
| 7 切字幕并锁定 | `make_srt.py` 只从镜头表和词时间切字幕，检查后登记SHA-256；烧入时只核对和截取 | 自动，不另设逐条审字幕节点 |
| 8 动态样片 | 通常15–20秒，含人物／复杂道具并展示完整绘制。真实引擎、手部和 Voice Studio 音轨；先检查无字幕版，再原样烧字幕 | 笔顺、节奏、累积、手部、字体及实际音画效果 |
| 9 整片 | 同一确认方法扩展整片；向 Voice Studio 交付完整触笔时点并接收混音；无字幕版检查通过后原样烧字幕 | 看整片定稿或修订 |
| 10 定稿归档 | 版本、校验值、工程、素材与问题清单；暂定定稿冻结，不暗中继续修片 | 按用户定稿决定记录；发布另需授权 |

审核在第1、3、4、8、9步。等待审核只暂停依赖该结果的工作，其他准备可继续。同一确认版本普通复用不重复询问；图稿通过不等于动画通过，样片通过不等于整片定稿。路径算法、手部、字体版式或声音策略变化，用同段样片重新验相关项。

审核须绑定真实文件及其依赖哈希，记录用户原意见。后来拒绝的版本和仅暂时接受的问题不得写成默认成功方案。历史B、自然短样、同输入哈希一致或技术检查通过都不是稳定音质保证；声音实验状态由 Voice Studio 维护。

## 调用与检查

- 需要声音时读 [Voice Studio接口](references/voice-interface.md)：仅传入文案、已选择的配置和视频事件时点，接收版本化音轨。声音问题回交该项目，不在白板侧实现克隆、训练、调速、滤波、笔声合成或混音。
- 图稿、笔顺、手部、排时、字幕与封装读 [制作方法](references/production.md)。
- 资源与审核登记读 [审核记录格式](references/review-schema.md)，运行 `scripts/check_episode.py`；它核对声明资源和记录，不证明听感、笔顺或完整对象覆盖。
- 第6步先查镜头表，第8/9步再对无字幕视频运行 `scripts/check_timing.py`。对象在提及后1.5秒内可辨、本句结束前画完，画面静止不超过3秒；缺数据是未完成，不能写通过。字幕变化或悬空手部运动不能代替画板节奏。
- 交付时说明当前步骤、具体文件、修改项、检查结果、未验证项与下一节点；提供可直接打开的本地媒体及审核页。复核播放和拖动，不用截图或HTTP成功冒充已听完整音频。打不开时修复交付入口，不要求用户反复猜路径。
- 需要参考工程或项目含保护清单时读 [工程参考与保护](references/reference-engine.md)。技能不内嵌某一集的路径、人物、声线或音量数值。

本人数字形象是另行验证的能力；不凭本 skill 授权付费、上传训练、发布或改动旧定稿。
