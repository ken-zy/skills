# 手绘白板故事视频

目标是讲清故事、保留人物和道具的完成度，并让画面随旁白自然建立。此 skill 编排制作过程，提供安全初始化和审核检查；不是输入文章后无需审核的一键视频模型。

## 开始与继续

1. 先读取用户提供的内容及已有本集文件，确认是在新建还是继续；用户已给出的题目、来源和约束直接沿用。文章与截图中的第一人称不自动归到用户身上。是否另查资料按本集要求决定，不能把首片“不查史料”的选择推广到所有题材。
2. 新视频使用新的独立目录。可运行 `python3 <skill目录>/scripts/init_episode.py --output <新目录绝对路径> --title <标题>`。脚本只建目录和工作表，不联网、不生成音视频、不安装软件；拒绝覆盖已有目录。项目已使用 `docs/videos/` 时继续该惯例。
3. 继续已有视频时读取 `episode.json`、旁白、镜头表和真实审核记录，从尚未完成的阶段接续。用户只要求某一阶段时完成该阶段，不擅自扩大到整片。
4. 已定稿／暂定定稿的目录视为只读，修订另建同级版本。首片 `/Users/jdy/Code/ai-ip-business-plan/docs/videos/01-01-republic/` 是只读参考；禁止原地运行其渲染、混音、预览或语音脚本。

## 默认制作方向

- 已认可的是浅暖底、少量黑蓝橙线条、人物及物件结构清楚、画面逐步累积、B 带手。横屏 1080p／30 fps 可作为首片继承值，用户的新平台或画幅要求优先。
- 简化对象数量与装饰，保留脸型、五官、衣领、辫子、日历翻角等辨识特征。不要把“少笔画”变成潦草几何人物；也不要用密集排线弥补结构问题。
- 先确认完整旁白，再用实际录音排时，不按字数把全部镜头锁死。不固定为 12 段、5 分钟或 0.35 秒段间停顿。
- 现阶段可沿用已认可的云希 `+10%` 临时声线；继承的是声线配置，不是首片音频。长期目标为用户本人声音。用户指定本人声线时检查现有能力和授权素材，不擅自降级为云希，也不默认上传人声或人像。
- 简单图形直接用路径；人物和复杂道具可生成线稿。画面创作用可用 imagegen 能力，若采用其 skill 则按需读取。旁白风格需要参考 jdy_writer 时先查找并读实际风格文件；未找到就说明，不假称已调用。

## 制作与审核顺序

| 阶段 | 实际产出 | 用户审核边界 |
| --- | --- | --- |
| 内容 | 完整分段旁白、内容取舍、逐段画面事件 | 新稿或正文实质变化由用户确认 |
| 声音 | 新声线先同段短样音，再完整旁白及实测时间 | 首次或更换声线审核；既有配置不反复选声，新全文仍听审 |
| 角色与关键画面 | 角色板；开场、核心解释、转折和结尾的图与对应旁白 | 主动提交，提醒用户判断及修稿；记录具体通过版本 |
| 动态样片 | 约 15–20 秒，使用计划用于整片的真实引擎、手部与混音 | 确认笔顺、节奏、内容累积、笔声；必要时加一个复杂道具片段 |
| 整片 | 语义时间轴、字幕、绘制、移镜、混音、完整导出 | 前述适用审核通过后制作，完整成片交给用户定稿或修订 |
| 定稿与归档 | 定稿校验值、版本、工程、素材清单、已知问题 | “暂定定稿”保留问题并冻结文件，不继续暗中修片；发布另看用户授权 |

等待审核只暂停依赖该结果的工作，可继续来源整理、工具探测和不依赖角色的准备。已确认版本普通复用不重复询问。内容、角色、关键镜头、声音发生实质改变时重新审核相关项；换路径算法、手部实现或混音策略也要用同段重新验动态，不把静态图通过当成动画通过。

不要替用户填“已通过”，不要把无回复当同意。审核证据可引用本会话明确意见；不要要求用户重复已经说过的话。批量提交角色和关键镜头，避免逐笔打断。

## 按需读取

- 写稿、排时、设计素材和混音：读 [制作方法](references/production.md)。
- 登记资产、审核结果、准备扩展整片或定稿：读 [审核记录格式](references/review-schema.md)，按说明运行 `scripts/check_episode.py`。它只检查声明过的文件与记录，不代替用户看片或自动识别遗漏角色。
- 借用首片代码、声音连接器、图像或归档：读 [工程参考与保护](references/reference-engine.md)。已有工程不是通用模板，禁止直接改标题后当新片运行。

## 必须保留的质量检查

**笔顺**：主体先可辨，再补关键细节；主轮廓／五官优先语义路径。自动骨架不等于真实笔顺。换位距离、提笔时间和最短可见笔画需匹配，正常速度看手是否跳跃，不只核对端点数学一致。

**节奏**：按概念标记出现、可辨、强调、停留和移镜时点。画不完优先减线、减对象或拆镜头，不偷偷加速已确认旁白。字幕估时不能称为逐字对齐。

**笔声**：主要长线、日期和重点圈画要能在最终 MP4 中听见，提笔静音，细碎线弱化。对比仅旁白、旁白加笔声、完整混音；轨道非零不代表用户能听见。不要沿用首片过弱电平作为通过标准。

**成片**：技术上核对可完整解码、字幕边界、音画时长、峰值；视觉上抽查绘制中／完成帧并正常速度看连续动作，声音由实际播放听审。无法执行的检查如实注明，不能以静帧或数值检查冒充通片验收。

未来加入本人数字形象时，先确认本人声音，再由同一旁白驱动出镜片段，审核身份、口型、神态与布局。声音变化要重新计算时间；主持层按需要隐藏，不强制全程空出头像框。当前没有已验证的数字人后端，不凭 skill 调用自动授权付费、上传训练、发布或改动旧定稿。
