## Outcome and sources

A portable Python 3.10+ standard-library CLI plus an agent skill for trustworthy public DeFi data. Supports entity discovery, protocol fundamentals, historical comparisons, market/chain overview, stablecoins, yields, with smaller price/options/OI helpers. It answers user-selected research questions without asserting financial advice, audited company profits, causality, or unavailable user activity. JSON is the machine contract; CSV is a reproducible long-form export. Natural-language analysis is performed by the invoking agent using returned facts, caveats and methods, not generated boilerplate by the CLI.

Reference workflow (not copied dependencies): https://github.com/DefiLlama/defillama-skills (defi-data and protocol-deep-dive). This official skill requires subscribed MCP; do not install it or imply its full coverage is free. API reference: https://api-docs.defillama.com/llms-free.txt ; adapters: https://github.com/DefiLlama/dimension-adapters and https://github.com/DefiLlama/DefiLlama-Adapters . Existing macro Python helper is a design reference, not a runtime dependency.

## V1 command contract

Global controls: `--format json|csv`, `--output PATH` (stdout default, refuse an existing file unless `--overwrite`), `--refresh`, `--no-cache`, optional explicit cache directory; raw results only via explicit `--raw` in JSON. No arbitrary URL or dynamic module arguments. Print structured JSON by default. `capabilities` and `--help` are offline.

Commands:
1. `search QUERY`: protocol name/slug substring candidates, returns canonical id/name/slug/category/chains/parentProtocol; never silently pick a name match. Bound default limit 20, maximum 100 with truncation indicated.
2. `protocol SLUG --metrics tvl,volume,fees,revenue,supply-side,holders --days 7,30,90,365` (defaults tvl,volume,fees,revenue; windows 7,30,90). `--start YYYY-MM-DD --end YYYY-MM-DD` is an alternative to windows. Parent/child scope is returned and validated across sources. Unsupported metrics are explicitly unavailable; never substitute parent data for a child. Supply-side is opt-in because coverage varies.
3. `compare SLUG [SLUG ...] --metrics ... --days ...`: 2-5 exact slugs; align comparison windows across the available chosen series for the same metric and disclose scope/category differences. Invalid/unavailable series never become zeros or vanish from results. No unbounded market-wide individual requests.
4. `market`: global TVL history, DEX-volume history and stablecoin USD-cap history, with available-window summaries.
5. `chains [CHAIN]`: list current chain TVLs, or exact-chain historical TVL plus chain DEX volume and fees/revenue. Chain identifier resolved from authoritative lists/returned chain names; chain gas and app protocol fees must not be conflated (label API scope explicitly).
6. `stablecoins [ID] --chain CHAIN`: global/chain stablecoin USD-cap history or single stablecoin metadata/chain distribution plus history where supplied. Numeric ID resolution via list, no ticker-to-asset guessing. Historical USD values must use totalCirculatingUSD. Non-USD pegs are never summed as USD at par; current supply and price are separate fields unless an explicitly supported conversion is available.
7. `yields --chain CHAIN --project SLUG --symbol TEXT --stablecoin --min-tvl N --limit N` or `yields --pool UUID`: filter current pools locally and get pool history on request. Separate apyBase, apyReward, total apy and tvlUsd; null APY remains null. Default sort TVL descending, optional explicit APY sorting; APY is not promised future yield.
8. `prices TOKEN [TOKEN ...] [--timestamp EPOCH]`: max 20 chain:address/coingecko:id values, current or historical price, individual timestamp/confidence and unavailable requested coins retained. No independent-price-verification claim, no trade execution.
9. `options SLUG --kind premium|notional --days ...`: same flow-series rules, premium/notional not interchangeable.
10. `open-interest [SLUG]`: current OI overview/exact protocol entry only. Even if upstream fields are named total24h/total7d, do not sum them or describe OI as trading volume. No promised historical OI comparison without validated instantaneous series.
11. `capabilities`: supported commands, hosts, documented/empirical status, unavailable domains, offline examples.

## HTTP and endpoint contract

Only HTTPS GET to fixed hosts: api.llama.fi (protocol/chain/DEX/fee/options/OI), stablecoins.llama.fi (stablecoin groups), yields.llama.fi (pools/chart), coins.llama.fi (prices). Endpoint-specific builders encode user values and validate slugs, dates, IDs, limits, tokens, nonnegative thresholds; prevent path/query injection. Do not follow redirects to arbitrary hosts: allow only these HTTPS hosts or report failure. Never fetch protocol-provided URLs in the transport layer. Bound response body (e.g. 32 MiB), 25-second request timeout, max 2 attempts; retry network/transient HTTP 429/5xx only. Respect numeric/date Retry-After; if requested wait exceeds 30 seconds report rate-limited instead of waiting or retrying early. Do not retry authentication/404/schema errors. Bound independent concurrency at 3, no background monitor or recurring jobs.

5-minute cache keyed by full URL in temporary/user-selected cache directory, atomic writes, preserves original fetched_at and source HTTP Date. Never overwrite fetched_at on cache hit. Ignore corrupt cache and refetch once; never mask a fresh request failure with expired cache. No caching HTTP failures. Cache persistence is best effort: disk failure must not discard valid fetched data. Do not install packages, request keys, or use browser fallbacks silently.

Endpoints: /protocols, /protocol/{slug}, /v2/chains, /v2/historicalChainTvl[/{chain}], /overview/dexs[/{chain}], /summary/dexs/{slug}, /overview/fees[/{chain}], /summary/fees/{slug}?dataType=..., /summary/options/{slug}?dataType=dailyPremiumVolume|dailyNotionalVolume, /overview/open-interest. Stablecoins host: /stablecoins?includePrices=true, /stablecoincharts/all[?stablecoin=ID], /stablecoincharts/{chain}[?stablecoin=ID], /stablecoin/{id}. Yield host: /pools, /chart/{pool}. Coins host: /prices/current/{coins}, /prices/historical/{timestamp}/{coins}.

Live verified 2026-09-30: protocol/volume/fees-supply-side polymarket-international, v2/chains, stablecoins list/global chart, yields/pools, coins current coingecko:ethereum, options derive, OI overview all returned valid JSON. `dailySupplySideRevenue` worked but is not in the current free-doc enum; mark empirical, per-protocol capability, not universal incentives/expenses. Document actual hosts differing from free-doc generic base URL. Spot checks are not a guarantee of future availability or every protocol's coverage.

## Data contract, identity and semantics

Each response: schema_version, generated_at, command, requested_scope, effective_scope, sources[], results[], warnings and status (ok/partial/unavailable). Each source: id, exact URL/params, fetched_at, http_date if present, cached, methodology and methodologyURL if supplied; each result references its source IDs. Rows: entity, metric, kind (stock/flow/rate), unit, observed_at or explicit period_start/period_end, value, previous_value, change_pct, status and coverage. Keep name/slug/parent/id per source so reconciliation cannot conceal mismatches.

Across protocol endpoints resolve requested slug against returned slug/module/name/id/parent metadata using documented explicit aliases; never assert identity from name resemblance. A parent result cannot satisfy a child request. Fail the affected metric when identity remains ambiguous; preserve other metrics. Unit validation accepts finite int/float values but rejects bool, NaN and infinity. Negative revenue/supply-side values remain valid when adapter supports them; do not use generic nonnegative filtering. No null-to-zero conversion.

Exit 0 for complete usable response, 1 for partial/unavailable required results, 2 for invalid CLI inputs. A valid observed zero is usable. Empty searches/lists have explicit empty status/count and are not network failures. No data is distinct from source failure. CSV uses normalized long records with provenance columns (source URL, fetched_at, window/observation, scope, status) and missing rows, not nested JSON in cells; guard spreadsheet formula injection in text cells. JSON preserves structured metadata; --raw exposes the exact authorized endpoint payload without transforming away missing fields.

## Time and math contract

All comparisons UTC. User-facing dates inclusive; internally use [start midnight, end+1 midnight). Default end is the minimum latest usable completed UTC date across required available comparison series; exclude current UTC day. Disclose each series' latest timestamp, chosen end and dropped newer days. Explicit dates are not silently shifted; future/current incomplete periods are rejected or explicitly partial with no complete growth claims. Wholly unavailable metrics do not force all results unavailable but remain listed; the set actually used for alignment is recorded.

Validate timestamps (finite integral seconds, plausible positive dates, reject future observations beyond clock tolerance); sort series, reject conflicting duplicate daily flow buckets, handle exact duplicates deterministically without double count and warn. Intraday flow buckets are not blindly summed into a daily series. Source schema must establish daily grain; otherwise mark unsupported. Daily stock observations may legitimately contain multiple snapshots: choose latest within the relevant UTC day with original timestamp retained. A latest null stock observation must remain missing, not silently roll back to an older numeric observation.

Flows sum only when every expected day has a finite observation. Return observed partial_sum separately from comparable value=null when a date is absent; coverage includes expected/observed/missing dates. Never forward-fill. Prior window has equal calendar length immediately before current. Percentage change requires positive prior denominator; zero/negative baseline yields null plus reason. Rates aggregate from numerators/denominators, not averages of daily rates. Stocks compare exact end-day observations to the exact prior end-day (for N-day window, end minus N days), never sum and never silently nearest-fill. Return dates/timestamps; when using period-end next-midnight snapshots, label that instant explicitly rather than mixing conventions. Implementation will use end-day latest snapshots consistently for stock comparisons.

Report upstream total24h/7d/30d separately with unknown end time unless supplied; do not overwrite or use them as if identical to reconstructed calendar windows. Do not subtract overlapping rolling totals for previous-period math. No automatic short-period annualization, P/S valuations, or causality claims. API histories can be revised; include fetch times.

For protocol diagnosis derive fee/volume ratio, revenue/fees retention, and revenue change decomposition only with verified matching entity, units, exact window and complete inputs. Supply-side is the adapter-defined distribution, not universally "marketing subsidies". Reconcile fees - revenue - supply_side with a documented rounding tolerance (e.g. max $1 per day, 1e-6*fees); disclose residual, never silently adjust values or infer missing components. No residual-based invention of salary, tax, net profit, or universal incentive totals. Missing data for one ratio does not suppress independent valid facts.

## Research workflows and boundaries

Protocol research: resolve requested entity -> fetch relevant metrics -> align and validate -> compute -> explain source-defined metrics -> show uncertainty/next evidence. Compare only user-requested or defensibly same-category entities, label category/filter/ranking universe. Polymarket example specifically selects polymarket-international; no special hardcoded numerical snapshots in production. Official metadata/adapter links are provenance, not proof of audits or safety. Growth decomposition is arithmetic, not causal inference. Active addresses are not unique people; user retention, market/wallet concentration, complete fundraising/hacks/unlocks/ETF/treasury data are not promised by this free API skill. No silent paid-host/browser fallback. Explicitly mark capability gaps. Existing CoinGecko/Binance validation rules in finance skills remain untouched; this skill's price endpoint is not an independent cross-check of upstream CoinGecko-derived prices.
